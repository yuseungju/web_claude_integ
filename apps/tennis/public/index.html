1
익스텐션 파일 다운로드

아래 세 파일을 동일한 폴더(예: 바탕화면/대치예약)에 저장하세요.

⬇
contentscript.js
자동 예약 스크립트
 ⬇
background.js
설정값 수신 스크립트
 ⬇
manifest.json
익스텐션 설정 파일
📁 폴더 구조 예시:
대치예약/
  ├─ contentscript.js
  ├─ background.js
  └─ manifest.json
2
크롬 익스텐션 관리 페이지 열기

크롬 주소창에 아래 주소를 입력하고 Enter를 누르세요.

chrome://extensions/
3
개발자 모드 켜기

익스텐션 관리 페이지 우측 상단의 개발자 모드 토글을 ON 으로 켜주세요.

확장 프로그램
개발자 모드
ON
4
폴더 불러오기

개발자 모드 활성화 후 나타나는 "압축해제된 확장 프로그램을 로드합니다" 버튼을 클릭하고, STEP 1에서 파일을 저장한 폴더를 선택하세요.

압축해제된 확장 프로그램을 로드합니다
확장 프로그램 패키징
5
설치 확인

익스텐션 목록에 "대치유수지 예약 자동화"가 표시되고 활성화(파란 토글)되어 있으면 설치 완료입니다.

🎾
대치유수지 예약 자동화
ID: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
ON
✓
설정 완료!

예약 사이트 계정

여기 등록한 계정으로 하나씩 로그인해서 예약확인 페이지 1~4쪽을 훑어 예약완료 건만 모읍니다. 비밀번호는 암호화해서 보관하고 화면에 다시 보여주지 않습니다.
