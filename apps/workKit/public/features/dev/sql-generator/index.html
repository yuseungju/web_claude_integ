🗄️ SQL 생성기

💡 사용법  ·  엑셀을 업로드하면 첫 번째 행이 컬럼명으로 표시됩니다 → 컬럼 / KEY 설정 영역에서 컬럼명을 클릭하여 KEY를 설정하세요. KEY 설정 후 INSERT를 생성하면 중복 체크 INSERT(이미 있으면 건너뜀)로 생성되고, DELETE는 KEY 조건으로 생성됩니다. 모든 필드 값은 작은따옴표('...')로 표시됩니다.
예시 엑셀 입력 (KEY: ID)
IDNAMEAMT
1홍길동1000
2김철수2000
생성되는 INSERT문 예시 (Oracle, 2건)
INSERT INTO TABLE_NAME (ID, NAME, AMT) SELECT '1', '홍길동', '1000' FROM DUAL WHERE NOT EXISTS (SELECT 1 FROM TABLE_NAME WHERE ID = '1');
INSERT INTO TABLE_NAME (ID, NAME, AMT) SELECT '2', '김철수', '2000' FROM DUAL WHERE NOT EXISTS (SELECT 1 FROM TABLE_NAME WHERE ID = '2');
